## Sad Hamster

Sad Hamster: «Путь к Счастью» — браузерная clicker-игра на React, где игрок помогает хомяку пройти пять стадий от одиночества до абсолютного счастья.

## Основной функционал

- Клики по хомяку приносят Сыркоины 🧀.
- Пять сюжетных стадий открываются по количеству накопленных Сыркоинов.
- Предметы магазина увеличивают число нажатий за раз и пассивный доход.
- Пассивный доход начисляется автоматически каждую секунду.
- Есть достижения за накопление валюты, клики, покупки и действия профиля.
- Есть ежедневные бонусы, квестовый интерфейс и уведомления.
- Есть отдельные регуляторы громкости эффектов и музыки.
- Музыка переключается на победный трек на стадии «Абсолютный Кайф».
- Приложение поддерживает PWA и может работать офлайн после установки.
- Профиль позволяет менять имя и изображение пользователя.

## Локальный запуск

Требования: Node.js и npm.

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет Vite, обычно `http://localhost:5173`.

Production-сборка:

```bash
npm run build
npm run preview
```

## Core loop

1. Игрок нажимает на изображение хомяка.
2. Игра рассчитывает награду за нажатие через текущий параметр `multiplier`.
3. Сыркоины добавляются к `points`, а рекорд обновляется в `maxPoints`.
4. Пассивный доход из `perSecond` постепенно увеличивает баланс.
5. Достижения проверяются после кликов, накопления валюты и покупок.
6. Накопленные Сыркоины тратятся в магазине на улучшения.
7. При достижении нового порога меняются настроение, изображение, фон и текст истории.

Если игрок не нажимает на хомяка пять секунд, появляется анимированная подсказка «КЛИК».

## Экономика

Основная валюта игры — Сыркоины 🧀. Внутри состояния профиля она хранится в поле `points`.

Каждый предмет магазина имеет:

- базовую стоимость `cost`;
- бонус к нажатиям `multiplier`;
- пассивный доход `perSecond`.

Цена следующей копии предмета рассчитывается так:

```text
текущая цена = floor(базовая стоимость × 1.213742069 ^ количество купленных копий)
```

Предмет появляется в магазине, когда его базовая стоимость становится не больше `maxPoints` игрока. Это означает, что предмет открывается после первого достижения соответствующего порога.

## Где хранятся данные

Весь игровой профиль хранится в браузере через `localStorage` под ключом `userProfile`. Логика чтения и записи находится в `src/hooks/useStorageState.ts`.

Профиль содержит имя, баланс, рекорд, клики, улучшения, достижения, громкость, музыку, косметические разблокировки и ежедневный бонус. Серверная база данных для игрового прогресса не используется.

Музыкальные и звуковые файлы находятся в `src/assets` и `src/assets/sounds`. Изображения стадий также подключаются из `src/assets`.

## Монетизация без реальной оплаты

В `src/components/MonetizationPanel.tsx` находятся три демонстрационные механики:

1. Ежедневный подарок на `2 500` Сыркоинов.
2. Симуляция rewarded-рекламы с наградой `5 000` Сыркоинов и временным cooldown.
3. Косметическая премиум-разблокировка рамки профиля за `25 000` Сыркоинов.

Платёжных систем, банковских данных и реальных покупок в проекте нет. Rewarded-реклама также не подключена к рекламной сети и работает только как игровая демонстрация.
